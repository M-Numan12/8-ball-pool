# 8 Ball Pool AI Shot Assistant 🎱

An experimental screenshot-based shot planner for Windows and iPhone. **No account credentials required.**

## iPhone / iPad
Open [Mobile Shot Planner](mobile/index.html) in a browser, or enable **Settings → Pages → Deploy from a branch → main / root** to get a public link:
https://m-numan12.github.io/8-ball-pool/mobile/

1. Tap **Load demo**, then **Find shot** to see a sample.
2. Or choose a screenshot using **Choose screenshot**.
3. Tap **Cue**, then the cue-ball center; **Target**, then target-ball centers; **Pocket**, then pocket centers.
4. Tap **Find shot** to draw an estimated cue-to-ghost path and target-to-pocket path.

On iPhone Safari: Share → **Add to Home Screen** to save a shortcut.

## Windows
Download the complete project ZIP shared in the ChatGPT conversation. Run the Python/Tkinter application using `pip install pillow` and `python app.py`.

## Limitations
This is a standalone local planning tool, **not** an automatic online game-playing bot, jailbreak app, native IPA, or anti-ban tool. Calculations are approximate and do not model realistic spin, cushion contact or power. It doesn't connect to Facebook, Google, Apple or Miniclip accounts, nor does it log you in or manipulate game data. Online multiplayer automation can violate game rules. No promise of ban avoidance.
